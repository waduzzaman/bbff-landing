# BBFF — Coming Soon

A simple one-page "coming soon" site. It shows a beaver, Canada's national animal, building a dam.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Files

- `app/page.tsx`: the page text
- `app/BeaverScene.tsx`: the 3D beaver-and-dam scene (Three.js)
- `app/globals.css`: all styles
- `app/layout.tsx`: page title and description
